# 模型推理数据流程说明

## 你的理解是否正确？

**完全正确！** 你的理解是准确的：

### 训练阶段
```
输入: 2021-2025年的历史数据 (X: 1462天 × 1246网格 × 31特征)
       ↓
模型: SpatioTemporalTransformer 训练 (学习时空模式)
       ↓
输出: best_model_trans.pt (保存的权重)
```

### 推理阶段（预测"今天"）
```
输入: "今天"往前30天的数据 (X: 30天 × 1246网格 × 31特征)
       │
       ├─ 历史犯罪序列 (滞后7天)
       ├─ 气象数据 (温度/降雨/降雪)
       ├─ OD流数据 (人流特征)
       └─ 静态特征 (POI/道路/照明等)
       ↓
模型: 加载 best_model_trans.pt (冻结权重，仅前向传播)
       ↓
输出: 未来7天预测 (今天+1天, 今天+2天, ..., 今天+7天)
       │
       ├─ 每个网格的期望犯罪数 E[Y]
       ├─ 风险等级 (极高/高/中/低)
       └─ Top 10% 热点区域列表
```

## 关键概念澄清

### 1. 输入窗口 (Lookback Window)
- **训练时**: 使用滑动窗口，比如用第1-30天预测第31天，第2-31天预测第32天...
- **推理时**: 使用最近30天，预测接下来的7天

### 2. 动态特征 vs 静态特征
| 特征类型 | 更新频率 | 示例 |
|---------|---------|------|
| **静态特征** | 不更新 | POI分布、道路网络、土地利用 |
| **动态特征** | 每日更新 | 历史犯罪、气象、OD流 |

### 3. 预测步骤详解

```python
# 假设今天是 2026-04-10

# 第1步：准备输入数据（自动从数据库/API获取）
X_input = {
    # 历史犯罪 (2026-03-11 至 2026-04-09, 共30天)
    'crime_history': load_crime_data('2026-03-11', '2026-04-09'),

    # 气象数据 (同样30天窗口)
    'weather': load_weather_data('2026-03-11', '2026-04-09'),

    # OD流数据
    'od_flow': load_od_data('2026-03-11', '2026-04-09'),

    # 静态特征（不变）
    'static': load_static_features()
}

# 第2步：模型推理（加载预训练权重）
model.load_state_dict(torch.load('best_model_trans.pt'))
model.eval()

with torch.no_grad():
    # 第3步：生成未来7天预测
    for day in range(7):
        pred = model(X_input, ...)

        # 预测日期
        pred_date = '2026-04-11' + day  # 明天开始的7天

        # 保存结果
        save_prediction(pred_date, pred)

        # 更新输入窗口（滚动预测）
        X_input = update_window(X_input, pred)
```

## 每日数据获取清单

要预测"今天"，你需要获取以下数据（今天往前30天）：

### 必须每日更新（动态特征）
1. **犯罪数据** (`crime_grid_timeseries.npy`)
   - 来源：警局案件记录系统
   - 更新：每日凌晨同步前一天案件

2. **气象数据** (`weather_features.npy`)
   - 来源：NOAA天气API
   - 更新：每日获取预报和历史

3. **OD流数据** (`dynamic_od_flow_1246.npy`)
   - 来源：交通局/共享单车/出租车GPS
   - 更新：每日聚合前一天的流动数据

### 无需每日更新（静态特征）
4. **POI数据** (`poi_features.npy`)
   - 更新频率：季度/年度

5. **路网数据** (`road_density.npy`)
   - 更新频率：年度

6. **语义嵌入** (`semantic_embedding_rag.npy`)
   - 更新频率：当POI/路网变化时

## 常见问题

### Q1: 如果缺少某一天的数据怎么办？
**A**: 使用插值或前一日的数据填充。模型对少量缺失数据有一定鲁棒性。

### Q2: 能否预测更远的未来（如30天）？
**A**: 可以，但精度会下降。建议最多预测7天，然后滚动更新。

### Q3: 新区域没有历史数据怎么办？
**A**: 模型使用静态特征（POI/道路）进行冷启动，随着数据积累会逐渐准确。

### Q4: 需要多大的计算资源？
**A**:
- 训练：GPU推荐（2小时）
- 推理：CPU即可（每天<5秒）
- Web服务器：普通云服务器（2核4G）
